# DVLD - Driving License Management System

A desktop application for managing driving licenses,
applications, tests, people, drivers, and related operations.

## Technologies

- C#
- .NET Framework 4.8
- Windows Forms
- ADO.NET
- SQL Server
- 3-Tier Architecture
- Object-Oriented Programming

## Architecture

Presentation Layer
        ↓
Business Layer
        ↓
Data Access Layer
        ↓
SQL Server

## Main Features

- People Management
- Users Management
- Applications Management
- Driving License Management
- Tests Management
- Drivers Management
- License Detention
- International Driving License
- Authentication & Permissions
